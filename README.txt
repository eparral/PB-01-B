SISTEMA DE GESTIÓN DE MASCOTAS

Archivos solicitados:
- main.py
- mascota.py
- perro.py
- gato.py
- conejo.py
- aplicacion_mascotas.py
- UML_Mascotas.drawio

Ejecución:
1. Abrir una terminal dentro de la carpeta del proyecto.
2. Ejecutar: python main.py

El programa demuestra:
- Herencia entre Mascota y Perro/Gato/Conejo.
- Encapsulamiento mediante getters y setters.
- Validaciones de las reglas de negocio.
- Polimorfismo mediante obtener_descripcion().
- Uso del setter para cambiar el costo de consulta.
- Catálogo completo y suma total de consultas.
